## 1. مقدمة ونظرة عامة على المشروع

منصة **«مكاسب رقمية»** هي منصة عربية متخصصة في التمكين الرقمي والتوجيه العملي، تستهدف المستقلين، روّاد الأعمال، صنّاع المحتوى، والمهنيين الرقميين. تم تصميم المنصة لدمج ثلاثة ركائز أساسية:
- **المعرفة والتوجيه:** عبر مقالات تطبيقية معمقة مقسمة إلى أربعة قطاعات (المال والأعمال، التكنولوجيا والابتكار، الإعلام الجديد، وأسلوب الحياة الرقمي).
- **التنفيذ الفوري:** عبر حاسبات ومولدات تفاعلية تساعد المستخدم على اتخاذ قرارات دقيقة (تسعير، عقود، أمان، تكاليف سحابية، إلخ).
- **التفاعل والتشارك:** عبر مجتمع تفاعلي يتيح تبادل التجارب ومشاركة مخرجات الأدوات.

### المكونات والتقنيات المستخدمة:
- **Framework:** Next.js 16.3 (App Router) مع React 19.2.8.
- **Styling:** Tailwind CSS v4، مع خطوط عربية Google Fonts (Cairo & JetBrains Mono) ونظام سمات متقدم يدعم ألوان تمييز تفاعلية (Accent Themes).
- **Backend & Database:** Supabase (PostgreSQL, Supabase Auth, Storage Buckets, Row-Level Security RLS).
- **Rich Editor:** Tiptap مع إمكانية تضمين الأدوات الحية داخل متن المقالات.
- **Testing & Quality:** Vitest، Zod schemas، Sentry error tracking، Unlighthouse.

## 2. التدقيق الفني وجودة الشيفرة البرمجية (Technical Audit)

تم إجراء فحص شامل للأكواد واختبارات السلامة النوعية والأسلوبية:

### أ. فحص الأنواع (TypeScript Check)
- **النتيجة:** مر بنجاح كامل بدون أي خطأ نوعي (`tsc --noEmit` Exit Code 0). تعريفات الأنواع في `types/database.types.ts` و `types/tools.ts` متطابقة مع هيكل الجداول.

### ب. فحص الأخطاء والتنسيق (ESLint Analysis)
تم رصد 2 أخطاء حقيقية تمنع تمرير الفحص الكامل و 1 تحذير:
1. **خطأ React 19 في التزامن (Calling setState synchronously in Effect):**
   - **الملف:** `components/theme/ProfileThemeSelector.tsx:18`
   - **السبب:** استدعاء `setMounted(true)` داخل `useEffect` يسبب إعادة تصيير متتالية (Cascading Renders) غير مرغوبة وفق قواعد React 19 الحديثة.
2. **خطأ مماثل في `ThemeToggle.tsx`:**
   - **الملف:** `components/theme/ThemeToggle.tsx:12`
   - **السبب:** تكرار نمط `setMounted(true)` داخل `useEffect`.
   - **الحل المقترح:** استخدام `useSyncExternalStore` أو التهيئة المناسبة بدون إطلاق setState متزامن داخل الخطاف.
3. **تحذير التبعيات الناقصة (Missing Dependencies):**
   - **الملف:** `ProfileThemeSelector.tsx:51`
   - **السبب:** عدم تضمين دالات التحديث `setTheme` و `supabase` في مصفوفة التبعيات.

### ج. أمان الشيفرة والتحكم بالصلاحيات (Security & Access Control)
1. **تسريب بيانات إدارية في الواجهة الأمامية:**
   - في `components/layout/Navbar.tsx` السطر 57:
     ```typescript
     const ADMIN_EMAIL = "mohammed.sss2013@gmail.com";
     ```
     **المخاطر:** كشف البريد الخاص بمدير النظام داخل كود الجافاسكربت العام في المتصفح.
     **الحل:** الاعتماد كلياً على الصلاحية المسترجعة من الخادم (User Roles) وعدم تضمين أي عناوين بريد ثابتة في الواجهات العامة.
2. **قواعد الأمان على مستوى الصفوف (RLS):**
   - تم التحقق من سلامة سياسات RLS في `supabase/schema.sql` لجداول `profiles`, `saved_tools`, `community_posts`, `user_roles`, `audit_logs`.
   - دالة `public.is_admin_user()` مُعدة بحماية `SECURITY DEFINER` ومسار `search_path = pg_catalog, public` الآمن.

### د. أداء التخزين المؤقت والـ Rendering
1. **تعارض التوجيهات في صفحة المقال الفردي:**
   - في `app/articles/[category]/[subcategory]/[slug]/page.tsx`:
     ```typescript
     export const dynamic = "force-dynamic";
     export async function generateStaticParams() { ... }
     ```
     وجود `force-dynamic` يُبطل تماماً عمل `generateStaticParams`، مما يجعل السيرفر يعيد توليد كل مقال في كل طلب للمستخدم بدلاً من الاستفادة من سرعة الـ Edge والـ ISR.
     **الحل:** استبدال `force-dynamic` بـ `export const revalidate = 3600;` (ISR).

## 4. تحسينات الأجزاء الدقيقة وتجربة المستخدم (Micro-interactions & UX Polish)

تعتبر التحسينات الصغيرة هي الفارق الحقيقي في مستوى الاحترافية وسلاسة الاستخدام:

1. **حالات التحميل الهيكلية (Skeleton Loading Screens):**
   - استبدال أيقونات الدوران (Spinners) بهياكل رمادية نابضة تُحاكي المقالات والبطاقات لمنع الانزياح البصري (Cumulative Layout Shift).
2. **تغذية راجعة حركية عند النسخ (Copy Feedback Animation):**
   - تحول أيقونة النسخ إلى أيقونة تحقق خضراء مع وميض خفيف وإشعار Toast فوري.
3. **تنسيق الأرقام والعملات حسب المعايير العربية:**
   - تطبيق `Intl.NumberFormat('ar-SA')` لعرض المبالغ والأرقام بفواصل الآلاف المنظمة (`10,000 ر.س` بدلاً من `10000`).
4. **تنبيه انقطاع الاتصال (Offline Detector Toast):**
   - إشعار لطيف باللون البرتقالي ينبه المستخدم عند فقدان الاتصال بالإنترنت أثناء الكتابة أو الحساب لتجنب ضياع المدخلات.
5. **شريط اختصارات لوحة المفاتيح:**
   - تفعيل اختصارات سريعة في المحرر (`Ctrl+B`, `Ctrl+I`, `Ctrl+K`) وفي الموقع (`Ctrl+K` للبحث السريع).
6. **مؤشر حالة كلمة المرور الحي:**
   - في صفحة التسجيل، عرض شريط أمان تفاعلي فوري يتغير لونه (أحمر، أصفر، أخضر) بناءً على معايير القوة أثناء الكتابة.
7. **زر التمرير للأعلى (Scroll to Top):**
   - زر عائم انسيابي يظهر تلقائياً عند تجاوز منتصف الصفحة في المقالات وصفحات الأدوات الطويلة.

## 5. الأمان، الأداء، والتوافقية مع محركات البحث (Security, Performance & SEO)

1. **توليد صور المعاينة الاجتماعية ديناميكياً (Dynamic OpenGraph via `@vercel/og`):**
   - توليد صورة OG تلقائية لكل مقال تحتوي عنوانه واسم الكاتب والوسوم وشعار مكاسب لرفع نسبة النقر في منصات التواصل.
2. **رؤوس الأمان للمتصفح (Security Headers):**
   - تفعيل رؤوس الحماية في `next.config.ts`:
     - `X-Frame-Options: DENY` (لمنع هجمات Clickjacking).
     - `X-Content-Type-Options: nosniff`.
     - `Referrer-Policy: strict-origin-when-cross-origin`.
     - `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
3. **الحد من معدل الطلبات (Rate Limiting):**
   - حماية مسارات المصادقة `app/login` والـ API من هجمات القوة الغاشمة (Brute-Force).
4. **خريطة الموقع وملف الروبوتات:**
   - تحديث `app/sitemap.ts` ليشمل جميع مسارات الأدوات الديناميكية والمقالات بشكل آلي مع إشارات التردد `changeFrequency: 'weekly'`.
